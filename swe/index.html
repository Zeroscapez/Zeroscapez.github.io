Grid Pathfinding Benchmark

Group project · Master's coursework, Fall 2026 · JPS and JPS+ next

A C# harness for benchmarking grid pathfinding algorithms on 8-connected maps. Implements A* with an octile-distance heuristic, a custom binary min-heap, and flat-array bookkeeping for speed, behind a common pathfinder interface so Jump Point Search variants can be compared head to head.

Parses plain-text and Moving AI benchmark maps, runs randomized start/goal queries with warm-up and averaged timings, and reports path cost, nodes expanded and runtime. An xUnit suite checks path validity, diagonal movement rules and correctness against a reference Dijkstra search.
